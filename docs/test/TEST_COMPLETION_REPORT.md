## 3. 코드 커버리지

## 5. 남은 위험
1. 호스트 권위 우회(DEF-001)와 비멤버 연결 노출(SEC-002 실측 전)이 친구 협동에서도 방해·정보 노출로 이어질 수 있음.
2. Steam 릴레이·2PC 실제 접속 미확인. FR-002·003·005 핵심 경로가 사용자 수동 시험에 의존.
3. 출시 빌드 메모리·참가자 FPS·반영 지연 미측정. 개발 빌드는 vSync 상한으로 FPS 여유가 가려짐.
4. 서버 틱 최악 5.57 ms(상한 6.0)와 GC 할당(P8 521 KB/s, 매 프레임 할당)이 M2 이후 증가할 수 있음.
5. 형상 관리(main 직접 커밋, DEF ID·`Closes:` 없음, dirty 출시 빌드)로 결함 추적·빌드 재현이 약함.
